# Web Technologies Lab Assignment

This project was developed as part of the Web Technologies lab assignment at COMSATS University Islamabad, Wah Campus. It contains a main landing page that provides access to four individual webpages.

## Project Overview

The main landing page serves as the entry point for the project. It presents four task cards, allowing users to navigate to each webpage.

## Tasks

### Task 1: Campus Management Page

A university-themed webpage featuring campus information, navigation, and a login section.

### Task 2: X-Style Landing Page

A social media-inspired landing page featuring sign-up and sign-in options.

### Task 3: Web Development Agency Homepage

A webpage for a web development agency, including a navigation bar, introduction, services section, and footer.

### Task 4: Student Registration Form

A student registration form containing text fields, dropdown menus, radio buttons, checkboxes, and other form elements.

## Technologies Used

- HTML5
- CSS3

## How to Run

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code or another code editor.
3. Open `index.html` in a web browser.
4. Use the links on the main landing page to access the individual tasks.

## Project Structure

The project contains the main landing page, separate HTML pages for the four tasks, and supporting files such as stylesheets and images where required.
